# 羽風 — Hanekaze

スマートフォンで遊べる、終わりのない滑空ゲーム。指一本で操作する。
煤けた丘陵に敷かれた工業地帯の裏手を、飛行船が滑っていく。

- **押している間** — 蒸気を抜いて機体を沈め、地形に張りついて下り坂で加速する。
- **離すと** — 浮力で斜面から舞い上がる。速いほど高く遠くへ飛ぶ。
- **着地** — 斜面と同じ角度で滑り込めば速度は落ちない。連続で決めるほど加速が乗る。
- **歯車** — 空中に連なる歯車を拾うと加速する。
- **霧** — 背後から煤煙の霧が追ってくる。進むほど速くなる。飲まれたら終わり。

出発するたびに地形の種が変わるので、丘も工場の並びも毎回違う。距離に応じて空は
暁・昼・夕・夜と巡る。記録はこの端末にのみ保存される。

## 画づくり

背景は一つの土地として成立するように、すべてコードで描いている。

- **遠景** — 対岸の工場群（ガスタンク・鋸屋根の工場・煙突）。煙は常に上がる。
- **中景** — 丘の尾根に沿って延びる配管と支柱、電柱と垂れた電線、ときおり小屋と
  煙突。どれも同じ線の上に連続して置かれるため、画面が変わっても同じ土地に見える。
- **地面** — 焼けた表土、錆色の土、石炭層と粘土層の縞、散らばる燃え殻。層は地形に
  沿って波打ちつつ、層ごとに少しずつずれる。
- **空** — 時刻で巡る配色、靄、月と星、煤けた雲。

配布素材（蒸気機関風アセットシート）は画風の参考として使い、実際に切り出して
使っているのは **飛行船・歯車・HUD のゲージ枠の3点のみ**（`assets/`、計 136KB）。
市松模様の背景はフラッドフィルで除去し、縁の灰色は周囲色で補正している。

## 構成

- `index.html` — ゲーム本体。描画は Canvas 2D、音は Web Audio API で合成。
  外部依存は Google Fonts（Zen Old Mincho / Zen Kaku Gothic New）のみ。
- `assets/*.png` — 上記3点のスプライト。

ブラウザで `index.html` を開けばそのまま動く（`assets/` が隣にあること）。
