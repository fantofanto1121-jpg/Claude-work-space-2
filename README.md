# 羽風 — Hanekaze

スマートフォンで遊べる、終わりのない滑空ゲーム。指一本で操作する。

- **押している間** — 翼をたたんで地形に張りつき、下り坂で加速する。
- **離すと** — 翼が開き、揚力で斜面から飛び出す。速いほど高く飛ぶ。
- **着地** — 斜面と同じ角度で滑り込めば速度は落ちない。連続で決めるほど加速が乗る。
- **霧** — 背後から墨色の霧が追ってくる。進むほど速くなる。飲まれたら終わり。

距離に応じて空は暁・昼・夕・夜と巡り、丘も遠景もすべて手続き的に生成されるため、
コースは無限に続く。記録はこの端末にのみ保存される。

## 構成

`index.html` 一枚で完結する。外部依存は Google Fonts（Zen Old Mincho / Zen Kaku Gothic New）のみ。
描画は Canvas 2D、音は Web Audio API で合成している。

ブラウザで `index.html` を開けばそのまま動く。
