# 羽風 — Hanekaze

スマートフォンで遊べる、終わりのない滑空ゲーム。指一本で操作する。
蒸気機関風の素材で、煤けた丘の上を飛行船が滑っていく。

- **押している間** — 蒸気を抜いて機体を沈め、地形に張りついて下り坂で加速する。
- **離すと** — 浮力で斜面から舞い上がる。速いほど高く遠くへ飛ぶ。
- **着地** — 斜面と同じ角度で滑り込めば速度は落ちない。連続で決めるほど加速が乗る。
- **歯車** — 空中に連なる歯車を拾うと加速する。
- **霧** — 背後から煤煙の霧が追ってくる。進むほど速くなる。飲まれたら終わり。

距離に応じて空は暁・昼・夕・夜と巡り、丘も遠景も打ち捨てられた機械も手続き的に
配置されるため、コースは無限に続く。記録はこの端末にのみ保存される。

## 構成

- `index.html` — ゲーム本体。描画は Canvas 2D、音は Web Audio API で合成。
  外部依存は Google Fonts（Zen Old Mincho / Zen Kaku Gothic New）のみ。
- `assets/*.png` — スプライト。配布素材（蒸気機関風アセットシート、JPEG）から
  市松模様の背景をフラッドフィルで除去し、縁の灰色を周囲色で補正して切り出したもの。
  飛行船・機関車・旋盤・金庫・配管・鉄屑・炉・歯車・煙・火花・HUD バーを使用している。

ブラウザで `index.html` を開けばそのまま動く（`assets/` が隣にあること）。
