# 火の粉 — Hinoko

スマートフォンで遊べる、終わりのない上昇ゲーム。指一本で操作する。
水の満ちていく坑道を、一粒の火が自力で昇っていく。

- **引く** — 画面のどこでも押して引く。引いた逆向きへ飛ぶ。狙っている間、時間はほとんど止まる。
- **離す** — 弾ける。岩棚に乗れば、また引ける。岩棚は下からはすり抜け、上からは乗れる。
- **鉄輪** — 当たると勢いが増す。壁は弾くだけで掴めない。
- **火の粉** — 拾うと、空中でもう一度だけ弾ける（最大2回分）。
- **水** — 下から満ちてくる。昇るほど速くなる。沈めば終わり。

坑道は出発のたびに生成し直される。高さに応じて坑底・岩盤・水脈・外気と
景色が巡り、その先も続く。記録はこの端末にのみ保存される。

## 画づくり

素材画像は使わず、形・色・光はすべてコードで描いている。

- 揺れる岩壁と、その内側を縁取る灯り
- 壁から張り出す岩棚、坑道を渡す梁、錆びた鉄輪
- 深度で移り変わる配色（坑底の琥珀 → 岩盤の青 → 水脈の緑 → 外気の白）
- 漂う塵、火の粉の尾、着地の土煙、水面の揺らぎと反射

## 構成

- `index.html` — ゲーム本体。描画は Canvas 2D、音は Web Audio API で合成。
  外部依存は Google Fonts（Zen Old Mincho / Zen Kaku Gothic New）のみ。

ブラウザで `index.html` を開けばそのまま動く。
