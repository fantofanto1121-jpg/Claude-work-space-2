# 空の城へ — Sora no Shiro

スマートフォンで遊べる、終わりのない上昇ゲーム。指一本で操作する。
雲海がせり上がる谷を、スライムが跳ねて昇っていく。

- **引く** — 画面のどこでも押して引く。引いた逆向きへ飛ぶ。狙っている間、時間はほとんど止まる。
- **離す** — はじける。浮島に乗れば、また引ける。島は下からすり抜けられる。
- **鉄輪** — 当たると勢いが増す。断崖は弾くだけで掴めない。
- **結晶** — 拾うと、空中でもう一度だけはじける（最大2回分）。
- **雲海** — 下からせり上がる。昇るほど速くなる。飲まれれば終わり。

谷は出発のたびに生成し直される。高さに応じて朝の谷・雲上・夕映え・星天と
景色が巡り、その先も続く。記録はこの端末にのみ保存される。

## 画づくり

素材画像は使わず、形・色・光はすべてコードで描いている。

- 草の生えた断崖、茂み、垂れる蔓
- 木組みに支えられた浮島、旗、渡された梁
- 空に浮かぶ城、遠くの浮島、流れる雲
- 金の鉄輪、青い結晶、吊りランタン
- スライムの潰れと伸び、雲海のうねり

## 構成

- `index.html` — ゲーム本体。描画は Canvas 2D、音は Web Audio API で合成。
  外部依存は Google Fonts（Zen Old Mincho / Zen Kaku Gothic New）のみ。

ブラウザで `index.html` を開けばそのまま動く。
